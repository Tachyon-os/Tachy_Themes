# Tachy_Themes

Custom themes for the Rain, Shiggy and Revenge Discord clients. Some started as CSS themes I converted to JSON, and the rest I made from scratch.

This is a passion project and I'm still learning as I go, so expect a few rough edges. I hope you enjoy them!

## Themes

- Monolith
- Monolith OLED
- Amethyst
- Brain Freeze
- Cinder & Flame
- Gray_one
- Nyctophobia
- Cerise
- Phosphor
- Vellum

Most themes come with a matching wallpaper in `Wallpapers/`.

## Installing

1. Open the theme you want in the `Themes/` folder and copy its link. Either of these formats works:
   - `https://raw.githubusercontent.com/Tachyon-os/Tachy_Themes/main/Themes/<file>.json`
   - `https://cdn.jsdelivr.net/gh/Tachyon-os/Tachy_Themes@main/Themes/<file>.json`
2. In your client, go to **Settings → Themes**, paste the link and turn the theme on.

Don't use the normal `github.com/.../blob/...` link. The client needs the raw file.
